3. WHAT IS IT FOR?
This software framework is engineered to act as an open-source "technological 
seed" for local communities. It provides immediate, executable 3D printing code 
(`ambient_vortex_generator.scad`) and machine-readable data profiles 
(`slicing_profile_tpu.json`) so that any independent maker space or workshop 
can print active testing prototypes locally out of pure, sustainable materials.

To ensure absolute circularity, the system mandates a single polymer family:
- PASSIVE RIGID CHASSIS: BASF Forward AM Ultrafuse TPU 64D (Density: 1.21 g/cm³).
- ACTIVE HARVESTING NODES: Lubrizol Estane Conductive Carbon TPU (1.18 g/cm³).

Because the entire structure belongs to a single molecular family, old or worn 
units do not become unrecyclable garbage. They can be melted down together and 
re-extruded into pristine raw printing filament an infinite number of times.
